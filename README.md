# Project 1 — Responsive Frontend Interface

DecodeLabs Full Stack Internship | Batch 2026

A responsive frontend interface for a simple web application, built with plain HTML, CSS, and JavaScript — no frameworks. Implemented as a personal portfolio layout to demonstrate the required structure (navigation, content sections, sidebar, and a form).

## Features

- Semantic HTML5 structure (`header`, `nav`, `main`, `article`, `aside`, `footer`)
- Mobile-first responsive layout using CSS Grid and Flexbox
- Breakpoints at 768px (tablet) and 1024px (desktop)
- Fluid typography with `clamp()`
- Accessible mobile navigation menu
- Project filter buttons (vanilla JS)
- Client-side contact form validation

## Tech Stack

HTML5 · CSS3 · JavaScript (no frameworks)
